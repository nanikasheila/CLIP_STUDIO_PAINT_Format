# CLIP STUDIO PAINT ファイル形式の仕様

CLIP STUDIO PAINT（CSP）の `.clip` と `.cmc` の形式を、実ファイルの観察と CSP での確認からまとめたもの。公式の仕様はない。
各記述には確度を付ける。

- **確認済み**: ライブラリで読み書きし、コーパス（V1、`.clip` 719 件・`.cmc` 42 件）か CSP での確認（V6）で確かめた
- **推測**: 値の分布や名前から考えたもので、確かめていない
- **未解明**: 意味が分からない

画素を持たないレイヤー（色調補正・グラデーション・べた塗り）と合成モード・レイヤー効果の規則は、CSP の書き出しとの照合の記録
（[V6](../validation/V6-made-files.md)、[V6b](../validation/V6b-generated-layers.md)）に、測った値と一緒に書いた。

## 数値の約束

特に書かない限り、整数はビッグエンディアン。文字列は UTF-16BE で、前に `u32` の文字数（コード単位の数）が付く。
例外はテキストの書式（リトルエンディアン、06 章）と、ブロックの zlib の長さ（リトルエンディアン、04 章）。
